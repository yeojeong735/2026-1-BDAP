# 주제 : 여러 나라 전자기기/스마트폰 사양 및 가격 분석 📱

### 메인 화면: "2025 글로벌 스마트폰 시장 대시보드"

[대시보드 상단 - 상호작용 필터 영역]

- 제조사 선택 (구현: st.multiselect): 애플, 삼성, 샤오미 등 원하는 브랜드만 필터링해서 볼 수 있게 합니다.

- 가격대/RAM 설정 (구현: st.slider): 사용자가 원하​​는 최소~최대 가격이나 RAM 용량을 슬라이더로 조절합니다.

[1 탭: 브랜드별 스펙 비교]

- 제조사별 평균 배터리 용량, 평균 카메라 화소 비교 (구현: Bar 차트)

- 화면 크기와 무게의 상관관계 (구현: Scatter 플레이 차트 - 화면이 커질수록 무거워지는지 시각화)

[2 탭: 가성비(가치) 분석]

- "가격 대비 성능" 지표를 직접 정의(예: RAM 크기 + 배터리 / 가격)해서 가장 가성비가 좋은 스마트폰 TOP 10 보여주기.

[3 탭: 나에게 맞는 스마트폰 추천 시스템]

- 사용자가 "나는 배터리가 5000mAh 이상이고, RAM이 8GB 이상이면서 가격은 $X 이하인 폰을 원해!"라고 필터를 조절하면, 조건에 맞는 스마트폰 리스트를 화면에 테이블(st.dataframe)로 띄워주는 기능.
