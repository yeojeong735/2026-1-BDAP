# 주제 : 글로벌 스마트폰 사양 기반 출시 가격 예측 📱

#### 선택한 데이터
- 이름 : Mobiles Dataset (2025)
- 출처 : https://www.kaggle.com/datasets/abdulmalik1518/mobiles-dataset-2025
- 크기 : 6 * 930
- 형식 : csv

#### 문제정의
- 핵심 문제 : 스마트폰의 하드웨어 사양 변수들(RAM, 배터리, 무게, 화면 크기, 카메라 성능)은 출시 가격에 어떠한 영향을 미치며, 가상의 하드웨어 스펙 조합이 주어졌을 때 데이터 기반으로 예측된 합리적인 출시 가격은 얼마인가

#### 예상난관
- 낮은 설명력 : 스마트폰의 가격은 RAM, 배터리 같은 '하드웨어 스펙' 외에도 '브랜드 가치(예: Apple 프리미엄)', '출시 연도(인플레이션)', '소재(티타늄, 플라스틱)' 등 눈에 보이지 않는 변수의 영향을 크게 받습니다. 수치형 하드웨어 스펙만으로 학습시킬 경우 예측 오차(MAE)가 커지거나 모델 설명력이 낮게 나올 수 있도 있음

--- 

### 🎛️ 사이드바 (공통 제어 영역)

구성 요소:

- st.multiselect: 분석하고자 하는 스마트폰 브랜드 선택 (Apple, Samsung 등).

- st.slider (가격): 글로벌 출시 가격 범위 제한 ($).

- st.slider (RAM): 최소 RAM 용량 기준 설정 (GB).

### 🔹 탭 1: 📊 브랜드별 시장 분석 (EDA)

시각화 내용:

- 왼쪽 차트: 사이드바에서 선택된 브랜드들의 평균 출시 가격($) 비교 바 차트 (Plotly).

- 오른쪽 차트: 제조사별 평균 배터리 용량(mAh) 비교 바 차트.

- 인사이트: 어떤 브랜드가 하이엔드(고가) 전략을 취하는지, 어떤 브랜드가 배터리 등 실용적 스펙에 집중하는지 한눈에 파악 가능.

### 🔹 탭 2: 📈 스펙 vs 가격 상관관계 (고급 시각화)

시각화 내용: 다차원 산점도 그래프 (px.scatter).

- X축: 기기 무게(Weight) / Y축: 출시 가격(Price)

- 점의 색상(Color): 제조사(Company)

- 점의 크기(Size): 화면 크기(Screen Size)

- 마우스 오버(Hover): 세부 모델명 노출

- 인사이트: 성능 사양(화면이 커지거나 무게가 무거워짐)이 가격 상승에 직접적인 영향을 미치는지 시각적으로 증명.

### 🔹 탭 3: 💡 맞춤형 스마트폰 추천 (데이터 탐색)

시각화 내용: 사용자가 사이드바에서 필터링한 조건에 완벽히 부합하는 스마트폰의 전체 목록을 가격이 낮은 순으로 정렬하여 출력.

기능: 하단에 st.caption을 활용해 "조건에 맞는 스마트폰이 총 X개 검색되었습니다"라고 실시간 상태 메시지 표시.

### 🔹 탭 4: 🤖 AI 가격 예측기

사용자 입력 인터페이스 (st.number_input 활용):

- 1열: RAM 용량(GB), 배터리 용량(mAh) 입력

- 2열: 기기 무게(g), 화면 크기(Inches) 입력

- 3열: 전면 카메라(MP), 후면 메인 카메라(MP) 입력

- 추론 매커니즘: 사용자가 가상의 스펙을 입력하고 예상 출시 가격 추론하기 버튼을 누르면, 백엔드에 저장된 Random Forest 모델이 실시간 추론 수행.

  -> 추론 성공 시 화면에 축하 풍선 애니메이션(st.balloons())이 터지며 사용자 경험(UX) 극대화.
