# 1. 문제 정의

## 1.1 분석 목적

최근 글로벌 스마트폰 시장은 고성능 하드웨어와 다양한 가격대의 제품이 출시되며 빠르게 변화하고 있다. 
하지만 스마트폰의 최종 가격은 단순한 하드웨어 사양뿐만 아니라 제조사의 브랜드 가치, 제품 전략 등 다양한 요소가 반영되어 소비자가 객관적으로 판단하기 어려운 경우가 많다.

본 프로젝트에서는 글로벌 스마트폰 사양 데이터를 기반으로 주요 하드웨어 요소와 가격 간의 관계를 분석하고, 머신러닝 모델을 활용하여 스마트폰 출시 가격을 예측하는 AI 기반 분석 시스템을 구축한다.

## 1.2 해결하고자 하는 문제

스마트폰의 주요 사양(RAM, 배터리 용량, 화면 크기, 무게, 카메라 화소 등)을 입력 변수(feature)로 활용하여 미국 출시 가격(`Launched Price (USA)`)을 예측하는 회귀 모델을 구축한다.

또한 학습된 모델을 웹 서비스(Streamlit)에 적용하여 사용자가 직접 스마트폰 사양을 입력하고 예상 가격을 확인할 수 있는 분석 환경을 제공한다.

# 2. 데이터 소개 및 탐색적 데이터 분석(EDA)

## 2.1 데이터 개요

본 프로젝트에서는 Kaggle의 Global Mobile Specifications Dataset (2025)을 활용하였다.

데이터셋은 글로벌 시장에 출시된 스마트폰의 제조사, 모델명, 하드웨어 사양 및 출시 가격 정보를 포함하는 CSV 형태의 정형 데이터이다.

- 데이터 크기: 15 * 930
- 주요 변수:
  - RAM
  - Battery Capacity
  - Weight
  - Screen Size
  - Camera Specification
  - Launched Price (USA)

---

## 2.2 EDA 결과

### 1) 제조사별 가격 전략 차이 확인

브랜드별 평균 출시 가격을 분석한 결과, 제조사별로 프리미엄 제품군과 가성비 제품군을 중심으로 서로 다른 가격 전략을 가지고 있음을 확인하였다.

일부 브랜드는 높은 가격대의 플래그십 제품을 중심으로 시장을 형성하고 있으며, 일부 브랜드는 높은 배터리 용량과 기본 성능 대비 낮은 가격을 강조하는 전략을 보였다.

### 2) 하드웨어 사양과 가격의 관계

화면 크기(Screen Size), 무게(Weight) 등 물리적인 제품 특성이 증가할수록 출시 가격이 증가하는 경향을 확인하였다.

이는 스마트폰 가격 형성 과정에서 하드웨어 사양이 주요 영향을 미치는 요소임을 보여준다.

## 2.3 데이터 전처리

데이터 분석 과정에서 미국 출시 가격이 `$39,622`로 기록된 이상치를 발견하였다.

해당 값은 전체 가격 분포를 크게 왜곡하는 값으로 판단하여 제거하였다.

전처리 이후:

- 데이터 개수: 930개 → 929개
- 가격 데이터 표준편차 감소
- 모델 학습 안정성 향상

또한 결측값이 포함된 데이터는 `.dropna()`를 활용하여 제거하였다.

# 3. 특성 엔지니어링(Feature Engineering)

## 3.1 가성비 지표 생성

소비자가 스마트폰 구매 시 가격 대비 성능을 고려한다는 점에 착안하여 새로운 파생 변수인 `Value_Score`를 생성하였다.

### Value Score

$$
Value\ Score =
\frac{(RAM \times 1000)+Battery\ Capacity}
{Launched\ Price(USA)+1}
$$

## 3.2 생성 목적

기존 데이터는 개별적인 하드웨어 성능만 제공하지만, Value Score는 가격 대비 성능 효율을 하나의 지표로 표현한다.

이를 통해 모델이 스마트폰의 가격 형성 패턴을 더욱 다양한 관점에서 학습할 수 있도록 하였다.

# 4. 머신러닝 모델 구축

## 4.1 모델 선택

본 프로젝트에서는 Random Forest Regressor 모델을 사용하였다.

스마트폰 가격 데이터는 여러 하드웨어 변수 간의 복합적인 관계가 존재하는 정형 데이터이며, 랜덤 포레스트는 이러한 비선형 관계를 효과적으로 학습할 수 있다는 장점이 있다.

선택 이유:

1. 다양한 변수 조합 학습 가능
2. 이상치 영향 감소
3. 정형 데이터 회귀 문제에서 높은 성능 제공

# 6. 결론 및 향후 개선 방향

## 6.1 프로젝트를 통해 얻은 점

- 데이터 분석 과정에서 EDA와 전처리가 모델 성능에 직접적인 영향을 준다는 점을 확인하였다.
- 데이터 수집 → 전처리 → 모델 학습 → 웹 서비스 구현까지 전체 머신러닝 프로젝트 흐름을 경험하였다.
- Streamlit을 활용하여 학습된 모델을 실제 사용자 서비스 형태로 배포하는 과정을 구현하였다.

---

## 6.2 한계점 및 개선 방향

현재 모델은 하드웨어 사양 중심으로 가격을 예측하기 때문에 제조사의 브랜드 영향력을 충분히 반영하지 못한다.

실제 스마트폰 시장에서는 동일한 하드웨어 사양이라도 브랜드 가치에 따라 가격 차이가 발생할 수 있다.

향후 개선 방향:

- 제조사(Brand) 변수를 추가
- One-Hot Encoding 적용
- 브랜드별 가격 프리미엄 요소 학습

이를 통해 더욱 현실적인 스마트폰 가격 예측 모델로 발전시킬 수 있다.
